# JANG MI Portfolio 2025

장미님의 CMS 포트폴리오를 복원하고 원본 20페이지 PDF 이미지를 포트폴리오 섹션으로 추가했습니다.

## 실행 방법

1. `start-server.bat` 실행
2. 자동으로 `http://localhost:8765` 접속

## 주요 기능

- CMS 데이터 기반 콘텐츠 렌더링
- GitHub 로그인 기반 편집 및 Publish
- 테마 프리셋 스위처
- 데스크톱·모바일 네비게이션
- 원본 PDF 및 20페이지 이미지 보기

## 주요 파일

- `index.html` — 포트폴리오 페이지 구조
- `css/jangmi.css` — 원본 포트폴리오 페이지 섹션 스타일
- `assets/images/jangmi/01-cover.jpg` ~ `20-closing-contact.jpg`
- `assets/docs/jangmi-architecture-portfolio-2025.pdf`
